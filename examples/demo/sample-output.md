## The hygiene signal

Note the difference in the **Providers** table between a well-maintained module
and one with a gap. For `cloudposse/terraform-null-label`, the same table reads:

| Name | Source | Version | Alias |
|---|---|---|---|
| `aws` | hashicorp/aws **(not declared)** | **`(unpinned)`** | — |

`(not declared)` means there's no `required_providers` block; `(unpinned)`
means no version constraint. iac-cartographer surfaces these inline so drift
and hygiene gaps are visible on the page instead of hidden in the code — and
the `iac-cartographer --lint` subcommand fails CI on the same rules.
